## Features ✨

- **Liquid Glass UI:** A beautiful, modern, and responsive interface with a glassmorphism design.
- **Multiple Calculator Modes:**
  - **Standard:** Basic arithmetic operations.
  - **Scientific:** Advanced functions like trigonometry, logarithms, exponents, and constants (π, e).
  - **Programmer:** Supports different number bases (Decimal, Hexadecimal, Octal, Binary) with bitwise operations.
- **History Tracking:** Saves recent calculations for easy recall.
- **Smooth Animations:** Engaging animations for button presses and display updates.
- **Keyboard Support:** Full keyboard accessibility for a seamless user experience.
- **Customizable Angle Mode:** Switch between degrees (DEG) and radians (RAD) for trigonometric functions.
- **Toast Notifications:** Provides feedback for actions like clearing history or errors.
- **Background Visuals:** Animated orbs create an immersive background effect.

## Tech Stack 💻

- **HTML:** For structuring the calculator interface.
- **CSS:** For styling, animations, and the liquid glass effect.
- **JavaScript:** For all calculator logic, interactivity, and mode switching.

## Usage 💡

The calculator is designed to be intuitive and easy to use. You can switch between different modes to access various functionalities.

- **Standard Mode:** Perfect for everyday calculations.
- **Scientific Mode:** Utilizes advanced mathematical functions for complex computations.
- **Programmer Mode:** Ideal for developers and engineers working with different number systems and bitwise operations.

## How to Use 🛠️

1.  **Open `calculator.html` in your browser.**
2.  **Select Mode:** Click on the tabs 'Standard', 'Scientific', or 'Programmer' to switch between modes.
3.  **Input Numbers:** Click on the number buttons or use your keyboard.
4.  **Perform Operations:** Use the operator buttons (+, -, ×, ÷, etc.) or keyboard shortcuts.
5.  **Use Functions (Scientific/Programmer):** Access specific functions by clicking the corresponding buttons.
6.  **Check History:** Click the '⏱' icon to view past calculations.
7.  **Clear:** Use 'AC' to clear everything or '⌫' to delete the last character.

**Example Calculations:**

*   **Standard:** `(5 + 3) * 2 = 16`
*   **Scientific:** `sin(90) = 1` (ensure angle mode is DEG)
*   **Programmer:** Convert `255` (DEC) to `FF` (HEX).
